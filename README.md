# NEXUS World Hub

The front door of mynexus.world — a deep-space hub with floating panels linking out to the live NEXUS apps, plus a Manifest of live builds and works in the forge.

- Static single-file site, no build step, no backend.
- Panels link to the live apps (My KEF, NEXUS Archive v3.1, Ecosystem Hub, OSINT Vault, Platform, Eye, BLE Radar, Duct, Fret Trace, Shake Lab, IoT Dashboard, Detect, Playground).
- Custom domain: mynexus.world (see Netlify domain settings).
